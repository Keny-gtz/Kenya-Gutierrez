# 🔄 Mi proceso de trabajo

### 01 · 💬 Conocemos tu proyecto

Conozco tus necesidades, objetivos, público y características del proyecto.

### 02 · 📋 Definimos la propuesta

Establecemos los servicios, alcance, entregables y tiempos.

### 03 · 🎨 Diseñamos y desarrollamos

Trabajo en la solución manteniendo comunicación durante el proceso.

### 04 · 🚀 Entregamos

Recibes el proyecto, diseños o materiales acordados.

### 05 · 🔧 Realizamos ajustes

Se realizan las modificaciones contempladas para finalizar el proyecto.
